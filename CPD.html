Module 1

Normal (Gaussian) Distribution

Application: Precision Engineering & Shaft Diameter Quality Control

Industry Problem Statement

A precision mechanical manufacturing plant produces metal drive shafts with a Target Shaft Diameter of 10.00 mm. Quality inspection guidelines specify tight tolerance limits: a Lower Specification Limit (LSL) of 9.90 mm and an Upper Specification Limit (USL) of 10.10 mm. Any shaft falling outside $[9.90\text{ mm}, 10.10\text{ mm}]$ is rejected. ML quality engineering systems continuously track the process mean ($\mu$), process standard deviation ($\sigma$), defect percentage, parts per million (PPM) failure rate, and process capability ($C_p$).

Mathematical Foundations

Probability Density Function (PDF):

$$f(x) = \frac{1}{\sigma \sqrt{2\pi}} e^{-\frac{1}{2}\left(\frac{x - \mu}{\sigma}\right)^2}$$

Standard Normal Transformation ($Z$-Score) & Pass Yield:

$$Z = \frac{X - \mu}{\sigma}, \quad P(a \le X \le b) = \Phi(Z_b) - \Phi(Z_a)$$

Module 2

Exponential Distribution

Application: Cloud Microservices API Inter-Arrival & System Reliability

Industry Problem Statement

In cloud web infrastructure (e.g., AWS Lambda, API Gateways), incoming client requests arrive according to a constant-rate Poisson arrival process. The continuous time elapsed between consecutive request arrivals (inter-arrival time $T$) follows an Exponential Distribution.

Important Engineering Distinction: Inter-arrival time measures the gap between incoming external network requests. It is NOT equivalent to server response time or server execution latency!

Mathematical Foundations

Probability Density & Mean/Variance ($\lambda$ in req/sec):

$$f(t) = \lambda e^{-\lambda t}, \quad E[T] = \frac{1}{\lambda}, \quad \text{Var}(T) = \frac{1}{\lambda^2}$$

Interval Probabilities & Memoryless Property:

$$P(T \le t) = 1 - e^{-\lambda t}, \quad P(T > t_1 + t_2 \mid T > t_1) = P(T > t_2)$$

Module 3

Central Limit Theorem (CLT)

Application: Smart Warehouse E-Commerce Order Packing Time Optimization

Industry Problem Statement

In a robotic fulfillment center (e.g., Amazon, Flipkart), individual order processing times follow a highly non-normal, skewed distribution (many fast small items, rare complex bulky orders). However, operations managers need to predict batch completion times for thousands of orders per shift. The Central Limit Theorem proves that the *average* order pick time across random sample batches of size $n$ will form a Gaussian normal distribution regardless of how non-normal the individual items are!

Mathematical Foundations

Population Mean ($\mu$) & Variance ($\sigma^2$):

$$\text{Arbitrary / Skewed Distribution } X \sim (\mu, \sigma^2)$$

Distribution of Sample Means ($\bar{X}$):

$$\bar{X}_n \xrightarrow{d} \mathcal{N}\left(\mu, \frac{\sigma^2}{n}\right) \quad \text{as } n \to \infty$$
